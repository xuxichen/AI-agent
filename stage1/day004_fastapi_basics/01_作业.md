## 第 1 题 · 九条请求，先把状态码写下来再打（16 分钟）

这个文件里有四条路由，**它们长这样，你先把四条抄进文件**（抄，不是默写，这一题不考默写）：

```python
@app.get("/orders/recent")       # 登记的是 recent 这个词本身
@app.get("/orders/{oid}")        # oid: int
@app.get("/users/{uid}/orders/{oid}")   # 两个都是 int
@app.post("/orders")             # payload: dict
```

### ① 建文件

```bash
cd stage1/day004_fastapi_basics
cat > code/python/hw01_urls.py <<'PY'
from fastapi import FastAPI

app = FastAPI()


@app.get("/orders/recent")
def recent_orders():
    return {"handler": "recent_orders"}


@app.get("/orders/{oid}")
def get_order(oid: int):
    return {"handler": "get_order", "oid": oid}


@app.get("/users/{uid}/orders/{oid}")
def get_user_order(uid: int, oid: int):
    return {"handler": "get_user_order", "uid": uid, "oid": oid}


@app.post("/orders")
def create_order(payload: dict):
    return {"handler": "create_order", "got": payload}
PY
```

## 第 3 题 · 四个端点、五行表，把昨天那张判据搬到服务上（16 分钟）

教案第五节演了三件事，但**漏了最关键的一格**：
「`await asyncio.sleep`（昨天第二节）在一个端点里等」的时候，别人进不进得来？
这一题就是把它补上。四个端点各 2 秒，只是「怎么个睡法」不同：

| 端点 | 写法 | 它自己要花 |
|---|---|---|
| `/a` | `async def` + `await asyncio.sleep(2)` | 2 秒 |
| `/b` | 普通 `def` + `time.sleep(2)` | 2 秒 |
| `/c` | `async def`，一个字都没等 | 0 秒 |
| `/d` | `async def` + `time.sleep(2)` | 2 秒 |

### ① 建文件

```bash
cd stage1/day004_fastapi_basics
cat > code/python/hw03_blocking_table.py <<'PY'
import asyncio
import time

from fastapi import FastAPI

app = FastAPI()


@app.get("/a")
async def a():
    await asyncio.sleep(2)
    return {"who": "a", "kind": "async def + await asyncio.sleep"}


@app.get("/b")
def b():
    time.sleep(2)
    return {"who": "b", "kind": "普通 def + time.sleep"}


@app.get("/c")
async def c():
    return {"who": "c", "kind": "async def，一个字都没等"}


@app.get("/d")
async def d():
    time.sleep(2)
    return {"who": "d", "kind": "async def + time.sleep"}
PY
```

```bash
cd code/python
uv run uvicorn hw03_blocking_table:app --port 8733
```

### ② 先填表再跑（**五行全填完才许敲第一条 curl**）

每一行的动作都一样：**先把第一个 URL 打到后台去，等 0.3 秒，再打第二个，只记第二个的秒数。**

| # | 后台在睡的是 | 你紧接着打的是 | 你猜几秒 | 实跑几秒 |
|---|---|---|---|---|
| 1 | `/a` | `/c` | | |
| 2 | `/b` | `/c` | | |
| 3 | `/d` | `/c` | | |
| 4 | `/d` | `/a` | | |
| 5 | `/a` | `/b` | | |

第 4 行和第 5 行是这一题的真考点：**它们都不是「快」也不是「慢」，是一个你能算出来的数。**
猜的时候把「它自己要不要睡 2 秒」和「它有没有被挡」分开算。
