### 6B · 现在写文件（30 分钟）

**做什么**：在 `stage1/day002_python_core/` 建 `calculator.py`，**从空白写**，
不许抄上面任何一段实验代码。它要满足六条要求：

| # | 要求 | 对应教案 |
|---|---|---|
| 1 | `running_total(nums, acc=None)`：返回**累计和**列表。例：`[1,2,3]` → `[1,3,6]`。不传 `acc` 时每次调用互相独立 | 二、三 |
| 2 | `class Calculator`：`__init__` 里 `self.value = 0` 和 `self.history = []` | 四 |
| 3 | 方法 `add(self, n)` 和 `sub(self, n)`：改 `value`，把**操作后的当前值**追加进 `history`，并 `return` 它 | —— |
| 4 | 你自己写一个装饰器 `log_call`，`@` 在 `add` 或 `sub` 上，打印 `-> <函数名>`，**必须带 `@functools.wraps(fn)`** | 五 |

### 如果你看到的不是这样

我在这台机器上故意写坏过三次，红项长这样，对着查：

| 红在哪 | 你大概率犯了 | 我实测的报错尾巴 |
|---|---|---|
| 只有 **2、3、4** 红 | `history = []` 写进了类体 | `c2.history 就成了 [5]`；第 4 项还会报 `实际 [5, 5, 3]` |
| 只有 **1、4** 红 | `running_total(nums, acc=[])` | 第 4 项 `running_total([9]) 应返回 [9]，实际 [1, 3, 6, 15]` |
| 只有 **5** 红 | 装饰器忘写 `@functools.wraps` | `Calculator.add 的名字变成了 'inner'` |
| **一项都不印**，只有一行就退出 | `@dataclass` 里直接给了 `= []` | `✗ calculator.py 导入阶段就炸了：ValueError: mutable default <class 'list'> for field items is not allowed: use default_factory` |

**第 4 行和其他三行不一样。** 前三行都是「某些项红」，第四个是**直接一行退掉**——
因为 `check.py` 连你的文件都 exec 不起来。而报的还是 `@dataclass` 主动抛的 `ValueError`。
这就是教案第六节那张表说的：**不报错的是最危险的，报错的是最负责的。**
