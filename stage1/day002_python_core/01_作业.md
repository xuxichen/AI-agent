### ④ 对上——**第 3 段是冤枉的，看这两行**

```

```

`p1` 和 `p2` 是**两个不同的列表**，而且那个默认列表**到实验结束还是空的** `([],)`。

为什么？把 `count` 和 `pick` 的函数体并排放：

```python

return chosen + [x]      # pick ：造一个新列表，默认的那个碰都没碰  ← 没 bug
```

所以今天真正的判据不是"**有没有写 `=[]`**"，而是：

> **那个只建了一次的默认对象，有没有被你的函数体原地改掉。**
> 不改它，写上是无害的（只是难看）；改了它，两个调用者就共享了。

**顺手记一件有用的事**：`check.py` 第 1 项会把 `pick` 判**红**。
它是用 AST 查写法的，看不见你改没改。
**检查器查的是写法，不是行为**——这条你以后天天要用。

## 第 3 题 · dataclass 的 dict 版本（12 分钟）

教案第六节只给了一个 `list` 字段。这一题**两个字段，一个是 dict**，
而且要在类里加一个方法。

### 要求

`code/python/hw03_cart.py`：

1. 一个 `@dataclass class Cart`，两个字段：
   `items: list` 和 `totals: dict`，**两个都要用 `field(default_factory=...)`**。
2. 一个方法 `add(self, name, price)`：把 `name` 追加进 `items`，
   把 `totals[name] = price`，然后 `return self.items`。
3. 造两个购物车 `c1`、`c2`，只往 `c1` 里加三个东西，然后印出
   `c1.items`、`c1.totals`、`c2.items`、`c2.totals`、`c1.items is c2.items`。
4. 最后加一行：`print(Cart().items, Cart().totals)`——**先猜这里印什么**。

### 该看到

```
['pen', 'cap', 'box']
{'pen': 3, 'cap': 5, 'box': 10}
[] {}
c1.items is c2.items : False
连续新建两个，字段也一样吗 : [] {}
```

**最后一行是这题的收口**：`Cart()` 造三个，就是三个独立对象，
`default_factory` 保证了这一点。它和第一、二节的规则是**同一条**：
建图纸那一刻只建一次 → 所以要把"每次建新的"这件事搬进一个**每次都会执行**的地方。
`default_factory` 搬进去的是"怎么造"，`__init__` 搬进去的是"造出来放哪"。

### 如果 `totals: dict = {}` 你会看到什么

**别猜，跑一次**（跑完记得改回 `field(default_factory=dict)`）：

```
ValueError: mutable default <class 'dict'> for field totals is not allowed: use default_factory
```

箭头照样指在 `@dataclass` 那一行。**第六节那三条证据，一条都不需要改就成立。**

## 排错对照表（每一条我都在机器上撞过，引文是 `check.py` 原话）

| 红在哪项 | 病因 | 你会看到的原话 |
|---|---|---|
| **2、3、4 三项** | `history = []` 写在 `Calculator` **类体**里 | `✗ 3. 行为 · 两个计算器互不污染 —— 只给 c1 加了一次数，c2.history 就成了 [5]`<br>`✗ 4. ... history 应是 [5, 3]（每次操作后的当前值），实际 [5, 5, 3]` |
| **1、4 两项** | `running_total(nums, acc=[])` | `✗ 4. ... running_total([9]) 应返回 [9]，实际 [1, 3, 6, 15]` |
| **只有 5** | 忘了 `@functools.wraps(fn)` | `✗ 5. ... Calculator.add 的名字变成了 'inner'`（内层函数叫什么就报什么） |
| **只有 4** | `add` / `sub` 没有 `return self.value` | `✗ 4. ... add(5) 应返回 5、sub(2) 应返回 3，实际 (None, None)` |
| **只有 4** | `history.append(n)` —— 追加的是传进来的 `n`，不是操作后的当前值 | `✗ 4. ... history 应是 [5, 3]（每次操作后的当前值），实际 [5, 2]` |
| **一项都不印，只有一行就退出** | `@dataclass` 里给了 `= []` | `✗ calculator.py 导入阶段就炸了：ValueError: mutable default <class 'list'> for field items is not allowed: use default_factory` |

最后那条红是今天最"对"的一种：**`@dataclass` 替你拦住了错**，
你连 `check.py` 的六项都看不到——它 exec 你文件的第一行就炸了。
**"一句话都没印"不是脚本坏了，是你的文件在顶层就崩了。**

其余五行都是**只红一项还是红三项**的差别，这一列比右列更值得看：
**类体共享会一次打断三项**（写法查出来、行为也错、端到端也错），
而忘 `return`、追错值只红第 4 项。**红的项越多，说明那个错统得越深。**
