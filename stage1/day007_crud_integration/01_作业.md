## 第 1 题 · 把 hw01_todos.py 迁移成能落盘的完整 CRUD（35 分钟，:8791）

教案第四节你拿到了一份完整的 items 服务。这一题是**迁移**：同一个手术，在 todos 上再做一遍——
文件里已经替你写好了 GET 三件套（列表 / 单项 / POST），你补剩下的四样：
PUT、DELETE、id 改「最大 + 1」、落盘 `todos.json`。做完有 14 条判据等着你。

### ① 建文件（原样粘，先别改）

```bash
cd stage1/day007_crud_integration
cat > code/python/hw01_todos.py <<'PY'
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()


class TodoIn(BaseModel):
    title: str = Field(min_length=2)
    done: bool = False


class TodoOut(BaseModel):
    id: int
    title: str
    done: bool


todos = [
    {"id": 1, "title": "写作业", "done": False},
    {"id": 2, "title": "买牛奶", "done": True},
]


@app.get("/todos")
def list_todos():
    return todos


@app.get("/todos/{tid}")
def read_todo(tid: int):
    for it in todos:
        if it["id"] == tid:
            return it
    raise HTTPException(status_code=404, detail="没有这个 id")


@app.post("/todos", response_model=TodoOut, status_code=201)
def create_todo(payload: TodoIn):
    data = payload.model_dump()
    data["id"] = len(todos) + 1
    todos.append(data)
    return data
PY
```

注意两处与教案的差异，它们**不是 bug，是有意留的**：

1. **404 是默认形状**（`{"detail":"没有这个 id"}`），不是教案那种 `{"code":404,"msg":...}`——
   因为这份文件没有注册异常处理器（Day 6 第四节的 `on_http`）。这一题不要求你补它，
   判据里 404 全部按默认形状写。
2. `TodoIn` 有一个 `done: bool = False` 字段——POST 时可以不传（默认 false），PUT 时必须传（全量替换，教案二 ③ 那句）。

### ② 五步手术（每步照教案的哪一节做，写在括号里）

按顺序做，**每做完一步先不起服务，五步全做完再一次起**：

1. **加 PUT** `PUT /todos/{tid}`（教案二 ②）：body 是 `TodoIn`，找到就整条替换
   `title` 和 `done` 两个字段、`save()`、`return it`；找不到 `raise HTTPException(404, "没有这个 id")`。
   成功码默认 200，**不写** `status_code=`。
2. **加 DELETE** `DELETE /todos/{tid}`（教案二 ② ⑥）：`status_code=204`，`items.pop(n)` 换成
   `todos.pop(n)`，找到 `save()` 后 `return None`；找不到同样 `raise` 404。**不许**加 `response_model`。
3. **id 改最大 + 1**（教案二 ⑧）：加一个 `find_biggest()`（把 `items` 全换成 `todos`），
   把 `create_todo` 里 `data["id"] = len(todos) + 1` 换掉。
4. **落盘**（教案三 ③ ⑤）：加 `import json`；把写死的 `todos = [...]` 换成
   `DB_FILE = "todos.json"` + `save()` + 自举 `try`（种子搬进 `except FileNotFoundError`）；
   然后给三个「改数据」的端点（POST / PUT / DELETE）各补一行 `save()`。
   **`save()` 的定义必须放在自举 `try` 之前**（教案三 ③ 第 2 问）。
5. 第 4 步里如果忘了把变量名全部换成 `todos`（比如 `json.dump(items, ...)`），服务会在请求时才炸——
   那正是 Day 6 第一节的 `NameError`。自查一遍：全文件搜 `items`，应该一个都不剩。

```bash

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()


class TodoIn(BaseModel):
    title: str = Field(min_length=2)
    done: bool = False


class TodoOut(BaseModel):
    id: int
    title: str
    done: bool


todos = [
    {"id": 1, "title": "写作业", "done": False},
    {"id": 2, "title": "买牛奶", "done": True},

@app.get("/todos")
def list_todos():

@app.get("/todos/{tid}")
def read_todo(tid: int):
    for it in todos:
        if it["id"] == tid:
            return it
    raise HTTPException(status_code=404, detail="没有这个 id")


@app.post("/todos", response_model=TodoOut, status_code=201)
def create_todo(payload: TodoIn):
    data = payload.model_dump()
    data["id"] = len(todos) + 1
    todos.append(data)
    return data


@app.put("/todos/{tid}", response_model=TodoOut)
def update_todo(tid: int, payload: TodoIn):
    for it in todos:
        if it["id"] == tid:
            it["title"] = payload.title
            it["done"] = payload.done
            return it
    raise HTTPException(status_code=404, detail="没有这个 id")


@app.delete("/todos/{tid}")
def delete_todo(tid: int):
    n = 0
    for it in todos:
        if it["id"] == tid:
            todos.pop(n)
            return None
        n = n + 1
    return None
```
